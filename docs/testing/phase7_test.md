# 阶段 7 测试数据 — 前端

## 1. 页面加载测试

### 测试 1.1：首次进入 Agent 页面

1. 启动前端: `cd frontend-vue && npm run dev`
2. 浏览器打开，登录系统
3. 点击左侧导航栏 "智能 Agent 助手"
4. 预期：
   - 页面标题显示 "智能 Agent 助手"
   - 显示学业导师介绍文字
   - 显示 6 个示例问题按钮
   - 输入框在底部可用
   - 无历史消息时显示空状态提示

### 测试 1.2：侧边栏入口

1. 确认侧边栏出现 "智能 Agent 助手"（AG）导航项
2. 该导航项无 menuCode 限制，所有登录用户可见
3. 点击后跳转到 `/agent`（hash 路由）

---

## 2. 发送消息测试

### 测试 2.1：成绩查询

1. 在输入框输入 "帮我查一下成绩"
2. 点击发送或 Ctrl+Enter
3. 预期：
   - 用户消息立即显示在右侧（金色头像 "我"）
   - 显示加载动画（三个跳动圆点 + "正在思考..."）
   - 加载完成后显示 assistant 回复（左侧 "师" 头像）
   - 回复下方显示工具调用标签：[成绩查询 ✓ 查询到 N 条成绩记录]
   - 回复内容为自然语言成绩报告

### 测试 2.2：知识问答

1. 输入 "系统怎么查成绩"
2. 预期：
   - 回复下方显示工具调用标签：[知识检索 ✓ 检索到 N 个相关片段]
   - 回复下方显示参考来源（含文件来源和文本预览）

### 测试 2.3：情绪陪伴

1. 输入 "考试压力好大"
2. 预期：
   - 回复无工具调用标签
   - 回复语气温暖、共情

### 测试 2.4：示例问题快捷输入

1. 点击示例问题 "帮我查一下我的成绩"
2. 预期：输入框自动填入该问题，并立即发送

---

## 3. 多轮对话测试

### 测试 3.1：会话延续

1. 发送第一条消息 "帮我查成绩"
2. 收到回复后，发送追问 "那数学呢"
3. 预期：
   - 追问和回复都追加到消息列表末尾
   - session_id 保持不变（通过 API 响应确认）
   - 顶部出现会话标签，当前会话高亮

### 测试 3.2：新建对话

1. 点击 "+ 新对话" 按钮
2. 预期：
   - 消息列表清空
   - 输入框可用
   - 再发消息会创建新 session_id

### 测试 3.3：加载历史会话

1. 重启页面后回到 Agent 页面
2. 预期：顶部会话列表显示之前的对话
3. 点击某个历史会话标签
4. 预期：消息列表加载该会话的全部历史消息

## 4. 错误处理测试

### 测试 4.1：网络断开

3. 预期：显示 "网络错误" 消息，不崩溃

### 测试 4.2：空消息

2. 预期：发送按钮 disabled，无反应

## 6. 全链路端到端测试

### 场景 1：学生查成绩
1. 学生登录（username = 学号）
2. 进入 Agent 页面
3. "帮我查成绩" → 期望返回成绩数据
4. "最近有进步吗" → 期望基于上一条数据分析趋势

### 场景 2：管理员帮学生查
1. 管理员 admin 登录
2. 进入 Agent 页面（需要手动构造带 student_no 的请求）
3. 预期能查到指定学生的成绩

### 场景 3：知识问答
1. 任意用户登录
2. "系统怎么查成绩" → 期望返回校务知识
3. "桃园三结义" → 期望返回名著知识

### 场景 4：情绪陪伴
1. 任意用户登录
2. "快要考试了好紧张" → 期望共情回复
3. 确认回复中不含工具调用标签
