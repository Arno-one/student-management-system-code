# 腾讯地图天气查询接口文档
## 一、接口概述
通过**行政区划编码(adcode)** 或 **经纬度坐标(location)** 二选一入参，查询指定区县的**实时天气、多日预报、24小时逐时预报**，支持附带空气质量、气象预警、生活指数等扩展数据。
- 请求方式：`GET`
- 请求地址：`https://apis.map.qq.com/ws/weather/v1/`

## 二、请求参数
| 参数名       | 是否必填   | 参数说明                                                     | 示例                                     |
| ------------ | ---------- | ------------------------------------------------------------ | ---------------------------------------- |
| key          | 必选       | 腾讯地图开发开发者密钥                                       | `key=OB4BZ-D4W3U-B7VVO-4PJWW-6TKDJ-xxxx` |
| adcode       | 二选一必填 | 行政区划编码，支持市/区县级别                                | `adcode=130681`                          |
| location     | 二选一必填 | 经纬度坐标，自动匹配所属区县天气                             | `location=39.905023,116.724502`          |
| type         | 可选       | 天气查询类型，默认`now`<br>`now`：实时天气<br>`future`：多日天气预报<br>`hours`：未来24小时逐时预报 | `type=future`                            |
| get_md       | 可选       | 仅`type=future`生效，预报天数<br>`0`：当日+未来3天(默认)<br>`1`：当日+未来6天 | `get_md=1`                               |
| added_fields | 可选       | 附加扩展字段，多参数逗号分隔<br>`alarm`：气象预警（仅now）<br>`index`：生活指数（仅future）<br>`air`：空气质量（now/future通用） | `added_fields=alarm,air`                 |
| output       | 可选       | 返回数据格式，默认`json`：`json/jsonp`                       | `output=json`                            |
| callback     | 可选       | JSONP回调函数名，output=jsonp时生效                          | `callback=getData`                       |

> 注意：GET请求参数值需要做URL编码处理

## 三、返回通用顶层结构
| 字段名         | 数据类型      | 是否必返        | 说明                            |
| -------------- | ------------- | --------------- | ------------------------------- |
| status         | Number        | 是              | 接口状态码，`0=成功`，非0为异常 |
| message        | String        | 是              | 状态描述信息                    |
| result         | Object        | 是              | 天气结果主体对象                |
| realtime       | Array[Object] | type=now必返    | 实时天气数据                    |
| forecast       | Array[Object] | type=future必返 | 多日预报数据                    |
| forecast_hours | Array[Object] | type=hours必返  | 24小时逐时预报数据              |

## 四、各业务返回字段详情
### 4.1 实时天气（type=now → realtime）
| 字段                 | 类型          | 必填 | 说明                                                         |
| -------------------- | ------------- | ---- | ------------------------------------------------------------ |
| province             | String        | 是   | 省份名称                                                     |
| city                 | String        | 是   | 城市名称                                                     |
| district             | String        | 是   | 区县名称                                                     |
| adcode               | Number        | 是   | 区县行政区划编码                                             |
| update_time          | String        | 是   | 天气数据更新时间                                             |
| infos                | Object        | 是   | 基础天气信息                                                 |
| infos.weather        | String        | 是   | 天气状况（晴/雨/雪等）                                       |
| infos.temperature    | Number        | 是   | 实时温度，℃                                                  |
| infos.wind_direction | String        | 是   | 风向                                                         |
| infos.wind_power     | String        | 是   | 风力区间（如4-5级）                                          |
| infos.wind_power_v2  | String        | 是   | 标准风力（如4级）                                            |
| infos.humidity       | Number        | 是   | 空气湿度，%                                                  |
| infos.air_pressure   | Number        | 是   | 气压，百帕                                                   |
| alarms               | Array[Object] | 选配 | added_fields=alarm才返回，气象预警<br>type_name：预警类型<br>level_name：预警等级<br>title：预警标题<br>pub_content：预警详情 |
| air                  | Object        | 选配 | added_fields=air才返回，空气质量<br>aqi/pm10/pm25/no2/o3/so2/co：对应污染物浓度 |

### 4.2 多日天气预报（type=future → forecast）
| 字段                                      | 类型          | 必填 | 说明                                                         |
| ----------------------------------------- | ------------- | ---- | ------------------------------------------------------------ |
| province/city/district/adcode/update_time | -             | 是   | 同实时天气定义                                               |
| infos                                     | Array[Object] | 是   | 单天预报数组                                                 |
| infos.date                                | String        | 是   | 预报日期 `yyyy-MM-dd`                                        |
| infos.week                                | String        | 是   | 星期                                                         |
| infos.day                                 | Object        | 是   | 白天天气                                                     |
| infos.night                               | Object        | 是   | 夜间天气                                                     |
| day/night.weather                         | String        | 是   | 天气描述                                                     |
| day/night.temperature                     | Number        | 是   | 温度                                                         |
| day/night.wind_direction/wind_power       | String        | 是   | 风向、风力                                                   |
| day/night.humidity                        | Number        | 是   | 湿度                                                         |
| indexes                                   | Array[Object] | 选配 | added_fields=index返回，生活指数<br>index_date：日期yyyymmdd<br>ids.name：指数名称<br>ids.level：等级<br>ids.desc：详情说明 |
| air                                       | Array[Object] | 选配 | added_fields=air返回，多日空气质量<br>air_date：日期yyyymmdd、aqi：空气质量指数 |

> 补充规则：
> 1. 生活指数：每日06:35前：前1天+当天+未来2天；06:35后：当天+未来3天，最多4天数据
> 2. 预报空气质量：每日08:05前：前1天+当天+未来3天；08:05后：当天+未来4天，最多5天数据

### 4.3 24小时逐时预报（type=hours → forecast_hours）
| 字段                                               | 类型          | 必填 | 说明                        |
| -------------------------------------------------- | ------------- | ---- | --------------------------- |
| province/city/district/adcode/update_time          | -             | 是   | 同实时天气定义              |
| infos                                              | Array[Object] | 是   | 逐时天气数组                |
| infos.hour                                         | String        | 是   | 预报时间 `yyyy-MM-dd HH:mm` |
| infos.info                                         | Object        | 是   | 单小时天气详情              |
| info.weather/temperature/wind_direction/wind_power | -             | 是   | 天气、温度、风向风力        |

## 六、调用示例
```http
# 获取adcode=130681城市未来多日天气预报（含生活指数+空气质量）
GET https://apis.map.qq.com/ws/weather/v1/?key=你的KEY&adcode=130681&type=future&get_md=1&added_fields=index,air

# 根据经纬度查询实时天气+预警+空气质量
GET https://apis.map.qq.com/ws/weather/v1/?key=你的KEY&location=39.905023,116.724502&type=now&added_fields=alarm,air

# 24小时逐时预报
GET https://apis.map.qq.com/ws/weather/v1/?key=你的KEY&adcode=130681&type=hours
```
