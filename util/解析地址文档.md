# 腾讯地图地址正向地理编码接口文档（地址→经纬度）
## 一、接口概述
将**文本地址**解析转换为GCJ02坐标系经纬度，同时返回省/市/区/街道/门牌结构化地址、区划编码、解析可信度、定位精度等级；支持标准/宽松两种解析策略。
> 请求方式：`GET`
> 请求地址：`https://apis.map.qq.com/ws/geocoder/v1/`
> 补充：批量解析请使用官方批量解析工具，本接口为单地址单次解析。

## 二、请求参数
| 参数名   | 必填 | 参数说明                                                     | 示例                                         |
| -------- | ---- | ------------------------------------------------------------ | -------------------------------------------- |
| key      | 必选 | 腾讯地图开发者密钥                                           | `key=OB4BZ-D4W3U-B7VVO-4PJWW-6TKDJ-xxxx`     |
| address  | 必选 | 待解析的原始地址<br>1. 标准模式(policy=0)地址必须携带城市，否则报错；<br>2. 地址参数**单独做URL编码**，key等其他参数不编码；<br>3. 地址越详细（省市区+街道+门牌号）解析精度越高 | `address=北京市海淀区彩和坊路海淀西大街74号` |
| policy   | 可选 | 地址解析策略，默认`0`<br>`0`：标准模式，地址必须包含城市，准确率高<br>`1`：宽松模式，可缺省城市，多地名重合易出错 | `policy=1`                                   |
| output   | 可选 | 返回数据格式，默认`json`，可选`json/jsonp`                   | `output=json`                                |
| callback | 可选 | JSONP回调方法名，output=jsonp时生效                          | `callback=getLoc`                            |

> 编码注意：仅对`address`后的地址原文做URL编码，`key/policy`等参数不参与编码。

## 三、接口返回字段说明
| 字段                             | 类型   | 是否必返 | 字段说明                                                     |
| -------------------------------- | ------ | -------- | ------------------------------------------------------------ |
| status                           | Number | 是       | 状态码，`0=请求成功`，非0为异常                              |
| message                          | String | 是       | 状态描述文案                                                 |
| request_id                       | String | 是       | 请求唯一ID，用于异常排查                                     |
| result                           | Object | 是       | 地址解析主体结果                                             |
| result.title                     | String | 是       | 【废弃字段】解析用原始地址，不建议业务使用                   |
| result.location                  | Object | 是       | GCJ02坐标系经纬度                                            |
| location.lat                     | Number | 是       | 纬度                                                         |
| location.lng                     | Number | 是       | 经度                                                         |
| result.address_components        | Object | 是       | 结构化省市区地址拆分                                         |
| address_components.province      | String | 是       | 省份名称                                                     |
| address_components.city          | String | 是       | 城市名称；省直辖县级市时与district同名                       |
| address_components.district      | String | 是       | 区县名称，无数据为空字符串                                   |
| address_components.street        | String | 是       | 街道/道路，无数据为空字符串                                  |
| address_components.street_number | String | 是       | 门牌号，无数据为空字符串                                     |
| result.ad_info                   | Object | 是       | 行政区划信息                                                 |
| ad_info.adcode                   | String | 是       | 6位行政区划编码                                              |
| result.reliability               | Number | 是       | 解析可信度：取值1~10<br>≥7：解析结果可信度高；＜7：结果误差偏大 |
| result.level                     | Number | 可选     | 解析精度等级，参考下方等级对照表，≥9点位精度优秀             |
| similarity、deviation            | -      | 是       | 废弃字段，不再使用                                           |

## 四、level解析精度等级对照表
| 取值 | 解析精度级别                 |
| ---- | ---------------------------- |
| 0    | 无法判别，结果不可信         |
| 1    | 城市级别                     |
| 2    | 区县级别                     |
| 3    | 乡镇/街道级别                |
| 4    | 村、社区级别                 |
| 5    | 开发区                       |
| 6    | 商圈、热点区域               |
| 7    | 道路                         |
| 8    | 道路附属点（路口、收费站等） |
| 9    | 门址（门牌点位）             |
| 10   | 小区、大厦                   |
| 11   | POI地标点位                  |
| ≥21  | 等效POI点位                  |

> 业务选用建议：`level≥9`可放心使用点位坐标。

## 五、调用示例
### 5.1 标准策略（默认policy=0，带城市）
```http
GET https://apis.map.qq.com/ws/geocoder/v1/?address=北京市海淀区彩和坊路海淀西大街74号&key=你的密钥
```
### 5.2 宽松策略（policy=1，可省略城市）
```http
GET https://apis.map.qq.com/ws/geocoder/v1/?address=彩和坊路74号&key=你的密钥&policy=1
```

## 六、补充说明
1. **坐标系**：返回经纬度为**GCJ02（国测局）坐标系**；
2. **海外地址**：本接口仅限国内地址，海外地址使用腾讯地图海外地理编码接口；
3. **结构化地址缺陷**：如需精准街道区划数据，需调用官方「智能地址解析」接口。
