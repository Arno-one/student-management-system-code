### Ollama

Ollama是建立在llama.cpp开源推理引擎基础上的大模型推理工具框架

本地化运行LLMs‌：无需依赖云端服务，直接在个人电脑（支持macOS/Linux/ubuntu/Windows）运行开源大模型（如Llama、Mistral等），保障数据隐私和离线使用

Ollama 支持多种操作系统，包括 macOS、Windows、Linux 以及通过 Docker 容器运行



下载URL

https://ollama.com/download

下载模型

https://ollama.com/search

安装后可以在命令行使用命令运行大模型

```cmd
# 下载和运行模型
ollama run 模型名称
# 列出本地已安装的模型
ollama list
# 删除本地模型
ollama rm 模型名称

```

在Linux上安装

```shell
curl -fsSL https://ollama.com/install.sh | bash

docker pull ollama/ollama

docker run -p 11434:11434 ollama/ollama


pip install open-webui

open-webui serve
```

### ModelScope

ModelScope社区上托管了数千个优质的GGUF格式的大模型（包括LLM和视觉多模态模型），并支持了Ollama框架和ModelScope平台的链接，通过简单的 `ollama run`命令，就能**直接加载运行ModelScope模型库上的GGUF模型**。

```cmd
# 本地安装Qwen2.5
ollama run modelscope.cn/Qwen/Qwen2.5-3B-Instruct-GGUF
# 安装DeepSeek 本地模型
ollama run modelscope.cn/unsloth/DeepSeek-R1-Distill-Qwen-1.5B-GGUF

# 启动ollama
ollama serve

# ollama加载魔塔社区的GGUF格式的大模型
ollama run modelscope.cn/Qwen/Qwen3-4B-GGUF
```

### 调用大模型接口

```python
# 兼容OpenAI客户端

from openai import OpenAI

# 实例化一个ollama的客户端
client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama"
)

response = client.chat.completions.create(
    model="qwen3.5:2b",
    messages=[
        {
            "role": "system",
            "content": "你是一个聪明的客服助手!"
        },
        {
            "role": "user",
            "content": "天空为什么是蓝色的?"
        }
    ],
    stream=False
)

print(response.choices[0].message.content)
```

mail_pass = "VWigDeCeNKgLjgst"

### ⚡️ 核心对比速览

| 维度         | **Ollama**             | **vLLM**                    | **llama.cpp**                 |
| ------------ | ---------------------- | --------------------------- | ----------------------------- |
| **核心定位** | **开箱即用**的部署工具 | **高性能**推理服务框架      | **极致轻量**的底层推理引擎    |
| **上手难度** | ⭐ (极简，一条命令)     | ⭐⭐⭐ (需配置环境)            | ⭐⭐⭐⭐⭐ (硬核，需编译/参数调优) |
| **运行格式** | GGUF (默认)            | HuggingFace (Safetensors)   | GGUF (原生支持)               |
| **硬件依赖** | CPU / GPU (自动调度)   | **NVIDIA GPU** (强依赖CUDA) | CPU / Apple Silicon / GPU     |
| **并发能力** | 弱 (适合单用户)        | **极强** (适合高并发)       | 弱 (适合单线程)               |
| **操作系统** | Win / Mac / Linux      | 主要 Linux (Win需WSL)       | 全平台 (含嵌入式)             |

### 🔍 深度解析

#### 1. Ollama：新手首选与开发利器

你可以把 Ollama 想象成**“大模型界的 Docker”**或者**“AI 界的 iPhone”**。它对底层的 `llama.cpp` 进行了高度封装，屏蔽了复杂的配置过程。

- ✅ 优点：
  - **极简体验：** 安装后只需一行命令（如 `ollama run qwen2.5`）即可下载并运行模型，自动识别并调用 GPU 加速。
  - **生态丰富：** 拥有庞大的模型库，支持一键拉取和更新。
  - **接口友好：** 原生提供 REST API，且兼容 OpenAI 接口格式，方便开发者快速接入应用。
  - **跨平台：** 在 macOS、Windows 和 Linux 上体验一致，对 Mac 用户特别友好（支持 Metal 加速）。
- ❌ 缺点：
  - **定制化受限：** 相比原生 `llama.cpp`，它对底层参数的调整空间较小。
  - **并发瓶颈：** 虽然适合个人使用，但在高并发场景下，吞吐量不如 vLLM。
- 🎯 适用场景：
  - 个人开发者本地调试、创意验证。
  - 学生党、普通用户想在本地快速体验大模型。
  - 构建轻量级的本地 RAG（检索增强生成）应用。

#### 2. vLLM：企业级生产环境的“性能怪兽”

vLLM 是专为**高吞吐量**和**低延迟**设计的，它是目前云端部署和大规模服务的首选框架。

- ✅ 优点：
  - **极致速度：** 采用 **PagedAttention** 技术（类似操作系统的虚拟内存管理），极大提高了显存利用率，推理速度极快。
  - **高并发：** 支持连续批处理（Continuous Batching），能同时处理大量用户的请求，吞吐量比传统方案高数倍。
  - **原生支持 HF 模型：** 直接加载 HuggingFace 格式的模型，无需转换。
- ❌ 缺点：
  - **硬件门槛高：** 强依赖 NVIDIA GPU 和 CUDA 环境，对 CPU 推理支持较差。
  - **系统限制：** 主要针对 Linux 优化，Windows 用户通常需要 WSL2 才能流畅运行。
- 🎯 适用场景：
  - 企业级 API 服务部署，需承载大量用户访问。
  - 多卡并行推理（Tensor Parallelism）。
  - 对推理延迟极其敏感的生产环境。

#### 3. llama.cpp：底层引擎与边缘计算之王

如果说 Ollama 是整车，`llama.cpp` 就是**发动机**。它是一个纯 C/C++ 编写的库，专注于在资源受限的硬件上运行模型。

- ✅ 优点：
  - **无依赖、轻量：** 没有复杂的 Python 环境依赖，编译后就是一个二进制文件，体积极小。
  - **量化之王：** 对 **GGUF** 格式支持最好，能通过量化技术（如 INT4）让大模型在普通笔记本甚至树莓派上跑起来。
  - **CPU 推理强：** 在没有 GPU 的情况下，依然能利用 CPU 流畅运行模型。
- ❌ 缺点：
  - **上手难：** 需要手动编译、处理依赖、转换模型格式，对非技术人员不友好。
  - **功能单一：** 专注于推理，缺乏服务治理、监控等企业级功能。
- 🎯 适用场景：
  - **边缘计算：** 树莓派、嵌入式设备、离线工控机。
  - **低配设备：** 只有 CPU 或显存很小的旧电脑。
  - **极致优化：** 需要深度定制推理逻辑的硬核开发者。

### 💡 我该如何选择？

- **如果你是普通用户或应用开发者：** 请直接选择 **Ollama**。它能帮你节省 90% 的配置时间，让你专注于模型本身和应用开发。
- **如果你要搭建公司内部的 AI 服务：** 且有 NVIDIA 显卡，请务必选择 **vLLM**。它的稳定性和并发处理能力是生产环境的最佳保障。
- **如果你只有一台旧笔记本，或者想在树莓派上玩 AI：** 请选择 **llama.cpp**（或者基于它的 `llama.cpp` 命令行工具）。它是让大模型在低配硬件上“跑起来”的唯一解。
