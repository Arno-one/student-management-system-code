学生信息管理
接口地址：

POST创建学生

/student/students

GET查询学生

支持：全部分页 / 按ID / 按学号 / 按班级

更新 / 删除 / 恢复学生

PATCH 更新只改填写的字段；DELETE 为逻辑删除；可恢复

POST新增成绩

/score/add

POST批量新增成绩

/score/batch_add —— 在下方填写 JSON 数组

PUT修改成绩   POST删除成绩

/score/update & /score/is_delete

GET查询成绩

/score/query —— 支持多条件、分页、排序

POST新建就业信息

/Employment/employment_create

GET查询就业信息

分页查询 /employment_list，或按ID查 /employment_get/{id}

修改 / 删除 / 恢复就业信息

PUT 修改、逻辑删除、逻辑恢复、物理删除

POST新增 / 修改班级

/class/create_or_update_class —— 传 id 则为修改，不传为新增

GET查询班级   DELETE删除班级

分页查询 /class/get_class，按ID查 /class/get_class/{id}，删除 /class/del_class

POST批量新增教师

/teachers —— 请求体是教师数组

GET查询教师

/teachers —— 多条件过滤 + 排序 + 分页

按ID查 / 更新教师

GET /teachers/{id} & PUT /teachers/{id}（只改填写的字段）

GET统计查询

点击下方按钮调用各类统计接口。skip/limit/age/grade 通用参数。

/work/evaluation —— 选择评价风格

POST文生图（通义万相）

/work/image

POST多轮记忆对话

/work/talks —— 同一 session_id 保持上下文；可清空记忆

GET天气查询 / 经纬度解析

/work/weather（经纬度或行政编码二选一）& /work/geocoder（地址转经纬度）

天气查询
地址解析为经纬度
