

## 学生成绩表 (student_score)

| 字段        | 类型         | 约束                       | 说明                   |
| ----------- | ------------ | -------------------------- | ---------------------- |
| id          | INT          | PK、自增                   | 成绩ID                 |
| student_no  | VARCHAR(50)  | NOT NULL                   | 学生编号               |
| exam_order  | INT          | NOT NULL                   | 考核序次               |
| score       | DECIMAL(5,1) | NOT NULL                   | 学生成绩               |
| is_deleted  | INT          | DEFAULT 0                  | 逻辑删除 0-未删 1-已删 |
| create_time | DATETIME     | DEFAULT NOW                | 创建时间               |
| update_time | DATETIME     | DEFAULT NOW、ON UPDATE NOW | 更新时间               |
