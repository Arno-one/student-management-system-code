# 学生管理系统 — 使用指南与规章制度

本文档面向本校学生、教师及管理员，介绍学生管理系统的功能模块、操作方法及相关规范。所有使用者须妥善保管账号信息，遵守系统使用规范，不得将账号转借他人使用。

---

## 一、系统概述

本学生管理系统集成以下功能模块：

| 模块 | 路径前缀 | 适用角色 |
|---|---|---|
| 学生基本信息管理 | /student | 管理员、教师 |
| 考核成绩管理 | /score | 管理员、教师 |
| 班级管理 | /class | 管理员 |
| 教师管理 | /teacher | 管理员 |
| 就业信息管理 | /Employment | 管理员、教师 |
| 统计分析 | /statistics | 管理员、教师 |
| AI 作业模块 | /work | 所有用户 |
| 邮件管理 | /email | 管理员 |
| NL2SQL 智能问数 | /nl2sql | 所有授权用户 |
| RAG 四大名著知识库 | /rag | 所有用户 |
| 智能 Agent 助手 | /agent | 所有用户 |
| 系统管理（RBAC） | /system | 管理员 |

系统采用基于角色的访问控制（RBAC），每个模块的查看、创建、修改、删除操作均需对应权限。用户登录后可使用的功能范围由管理员分配的角色决定。

## 二、登录与账号安全

### 登录方式

系统支持 Web 端登录。打开系统网址后，输入账号和密码完成身份验证，即可进入系统首页。首页展示当前用户有权访问的功能模块。

### 默认管理员账号

系统预置管理员账号 `admin`，初始密码由部署时配置。首次登录后建议立即修改密码。

### 账号安全要求

- 所有用户须妥善保管个人账号密码，严禁转借、共用账号。
- 学生账号为本人学号，初始密码由管理员统一分配，首次登录后须及时修改。
- 若发现账号异常登录，需立即修改密码并联系管理员处理。
- 管理员可在系统管理模块中对用户账号进行开通、禁用、密码重置等操作。

### 修改密码

登录后可在个人中心修改密码，需输入原密码和新密码。密码修改后立即生效，下次登录使用新密码。

## 三、学生基本信息管理

### 功能概述

学生基本信息管理模块支持对学生档案的增删改查操作，包含以下核心能力：

- **单条录入**：通过表单手动填写学生信息并提交创建。
- **自然语言智能录入**：用自然语言描述学生信息，系统通过大模型自动提取关键字段并填入表单。例如输入"新增学生张三，学号S2024001，班级3班，男，20岁，计算机专业本科"，系统会自动填充对应字段。
- **Excel 批量导入**：下载标准模板，按模板填写学生数据后上传，系统批量导入。
- **Excel 导出**：将当前查询结果导出为 Excel 文件。

### 学生信息字段

学生档案包含以下字段：学号（唯一标识）、姓名、班级ID、性别、年龄、籍贯、毕业院校、专业、学历、入学时间、毕业时间、顾问编号。

### 查询与筛选

支持按学号、姓名、班级、年龄范围等条件筛选学生列表，结果分页展示。

### 删除与恢复

系统采用逻辑删除机制。删除操作不会物理删除数据，被删除的学生可通过恢复功能还原。物理删除仅管理员可操作且不可逆。

## 四、考核成绩管理

### 功能概述

成绩管理模块用于录入和查询学生的考核成绩。每次考试以"考试序次"（exam_order）区分，如第 1 次考试、第 2 次考试。

### 成绩录入

- **单条录入**：输入学号、考试序次和成绩（0-100，支持一位小数）即可新增一条成绩记录。系统会校验学号是否存在于学生表中，以及该学生当前序次的成绩是否已存在。
- **批量录入**：一次提交多条成绩记录，系统逐条校验后批量入库。
- **自然语言智能录入**：用自然语言描述成绩信息，系统自动提取。例如"学生S2025001第1次考试成绩85分"。
- **Excel 批量导入**：下载标准模板填写后上传导入。

### 成绩查询

支持多条件组合查询：按学号、考试序次、班级、分数范围筛选，支持分页和排序。查询结果会关联显示学生的班级和姓名信息。

### 成绩修改与删除

支持修改已有成绩记录，同样采用逻辑删除机制。注意：同一学生同一考试序次的成绩只能存在一条。

## 五、班级管理

班级管理模块支持班级信息的创建、修改、删除和查询。班级字段包括班级名称、班级编号等基础信息。删除同样采用逻辑删除。

## 六、教师管理

### 功能概述

教师管理模块维护教师基本信息档案，支持单条录入、批量 JSON 创建和 Excel 批量导入导出。

### 教师信息字段

包括：姓名、性别、出生日期、联系电话、邮箱、职务、所带班级ID、入职日期。

### 批量导入

可下载标准 Excel 模板，按模板填写教师数据后上传。系统逐行校验，合格的入库，不合格的跳过并返回具体原因。也支持通过 JSON 数组格式批量创建。

---

## 七、就业信息管理

### 功能概述

跟踪学生毕业就业情况，记录学生的就业公司、薪资、offer 时间等信息。

### 就业信息字段

包括：学号、学生姓名、班级ID、就业开放时间、offer 下发时间、公司名称、薪资。

### 操作说明

支持单条创建、修改、查询（按 id 精确查询或按姓名/班级/公司名分页查询）、逻辑删除、恢复和物理删除。同样支持自然语言智能提取录入。

## 八、统计分析

统计分析模块提供跨模块的聚合数据查询，帮助教师和管理员掌握整体情况：

- **年龄分布统计**：查询年龄大于指定值的学生列表。
- **学生总人数统计**：统计全校在册学生总数。
- **成绩优秀学生筛选**：查询每次考试成绩均在指定分数线以上的学生（如每次考试都在 85 分以上）。
- **班级维度统计**：按班级聚合分析学生数据和成绩数据。

## 九、AI 作业模块

AI 作业模块集成多项大模型驱动的智能能力：

### 学生评价生成

根据学生姓名、性别和最新考试成绩，自动生成个性化评价。支持四种评价风格：

1. **幽默风格**：轻松诙谐的表达方式。
2. **严肃风格**：正式、严谨的评价语气。
3. **激励风格**：鼓励型表达，适合进步明显或需要信心的学生。
4. **批判风格**：指出问题，督促改进。

使用方法：传入学生 ID 和期望的风格即可生成。

### 文生图

调用阿里云通义万相大模型，根据文字描述生成图片。输入一段 prompt 描述即可获得生成的图片。

### 天气查询

集成腾讯地图 API，支持根据经纬度坐标或行政区划编码查询实时天气、多日预报和 24 小时逐时天气。

### 多轮对话

支持创建对话会话、在会话中进行多轮 AI 对话，系统会自动维护对话上下文、生成会话摘要并识别用户的对话风格偏好。

## 十、邮件管理

## 十一、NL2SQL 智能问数

### 功能概述

NL2SQL（Natural Language to SQL）模块允许用户通过日常口语化的自然语言查询数据库，无需手动进入各模块筛选数据。

### 使用方法

进入 NL2SQL 页面，在输入框中用自然语言描述查询需求，系统会自动将问题转换为 SQL 语句，经安全校验后执行并返回结果。典型示例：

- "张三的平均成绩是多少？"
- "查询3班所有学生的成绩"
- "统计每个班级的学生人数"

### 安全机制

- 生成的 SQL 经过安全校验（仅允许 SELECT、禁止危险操作）。
- 系统使用只读数据库账号执行查询，防止误操作修改数据。
- 所有查询记录自动留存，便于审计追溯。
- 支持查询缓存：相同问题短时间内重复查询直接返回缓存结果。

### 多轮对话

NL2SQL 支持创建会话，在同一个会话中可以连续追问，系统会自动维护上下文。会话历史可在左侧面板查看。

## 十二、RAG 四大名著知识库

### 功能概述

基于 RAG（检索增强生成）技术的知识问答系统，当前知识库涵盖《三国演义》《水浒传》《红楼梦》《西游记》四部古典名著（前 30 回）的原文内容和问答对。

### 技术路线

1. **查询改写**：将用户问题改写为更适合检索的形式。
2. **向量化嵌入**：使用阿里云 text-embedding-v3 模型生成查询向量。
3. **混合检索**：结合语义检索（Milvus 向量数据库）和关键词检索（BM25），通过 RRF 算法融合排序。
4. **CrossEncoder 精排**：使用 BAAI/bge-reranker-v2-m3 模型对候选片段重排序，提升 Top 结果准确性。
5. **答案生成**：将最相关的原文片段组装为上下文，由 DeepSeek 大模型生成自然语言回答。

### 使用方式

在 RAG 知识库页面输入与四大名著相关的问题，例如"桃园三结义是哪三个人？""孙悟空大闹天宫在第几回？"，系统将从名著原文中检索相关内容并生成回答，同时标注来源片段。

### 精排开关

可选择开启或关闭 CrossEncoder 精排。开启精排可提高答案准确性，但会增加约 300 毫秒延迟。

## 十三、智能 Agent 助手

### 功能概述

智能 Agent 是系统二阶段新增的 AI 能力，不同于传统的"一问一答"聊天机器人，Agent 能理解用户意图、制定执行计划，并调用系统工具完成实际任务。

### 学业导师 Agent

当前默认角色为"学业导师"，定位为温和、鼓励型的智能助手，具备以下能力：

- **成绩查询**：学生可自然语言询问成绩，如"帮我查一下我的成绩""我数学怎么样"，Agent 自动调用成绩查询工具获取数据。
- **学业分析**：结合成绩趋势和统计数据，给出学业表现分析和改进建议。
- **知识问答**：基于 RAG 知识库回答名著相关或制度相关问题。
- **情绪陪伴**：对学生表达的考试压力、学习焦虑等情绪给出温和的共情回应。

### 使用方式

进入 Agent 对话页面，选择角色后即可开始对话。Agent 会记住对话上下文，支持多轮追问。例如：
- 用户："帮我查一下我的成绩。"
- Agent 返回成绩数据后，用户追问："那最近有进步吗？"
- Agent 能结合前面的成绩数据，分析趋势并给出回答。

## 十四、系统管理与权限控制

### RBAC 权限模型

系统采用"用户—角色—权限"三层 RBAC 模型：

- **用户（SysUser）**：系统登录账号，包含用户名、真实姓名、手机号、邮箱等信息。
- **角色（SysRole）**：如 admin（管理员）、teacher（教师）、student（学生）。一个用户可拥有多个角色。
- **权限（SysPermission）**：细粒度的操作权限编码，如 `student:create`（创建学生）、`score:view`（查看成绩）。权限分为菜单权限和操作权限，菜单权限控制前端页面可见性，操作权限控制 API 访问。

### 管理员操作

管理员可在系统管理模块中进行以下操作：
- 创建、编辑、禁用用户账号。
- 分配用户角色。
- 创建和配置角色及其权限。
- 查看和管理权限列表。

### 权限编码示例

常见权限编码格式为 `模块:操作`，例如：
- `student:view` — 查看学生信息
- `student:create` — 新增学生
- `student:update` — 修改学生信息
- `student:delete` — 删除学生
- `score:view` — 查看成绩
- `nl2sql:use` — 使用 NL2SQL 智能问数
- `work:use` — 使用 AI 作业模块

## 十五、通用使用规范

### 数据删除说明

系统中大部分模块（学生、成绩、就业、班级、教师）采用**逻辑删除**机制。逻辑删除后数据在数据库中保留，可在需要时恢复。物理删除为不可逆操作，仅管理员可执行。

### 数据安全

- 系统内所有学生学籍信息、成绩数据、个人隐私信息均为内部保密数据，不得私自截图、转发、外泄。
- NL2SQL 查询使用只读数据库账号，所有查询日志自动留存。
- 禁止利用系统漏洞进行违规操作、篡改数据或恶意高频查询。

### 自然语言录入说明

学生、成绩、就业三个模块均支持自然语言智能录入。用户用自然语言描述信息后，系统通过大模型自动提取关键字段。提取结果会展示在预览区供用户确认和补填，确认无误后再提交。若大模型提取结果不完整或错误，用户可手动修改补充。

## 附录：系统技术栈

- 后端框架：FastAPI（Python）
- 数据库：MySQL + SQLAlchemy ORM
- 向量数据库：Milvus（RAG 知识库）
- 大模型：支持 DeepSeek、阿里云通义千问、Ollama 本地模型等多种 provider
- 前端：Vue 3 + Vue Router
- 认证：JWT Bearer Token + PBKDF2-SHA256 密码哈希
- 权限：RBAC（用户—角色—权限三层模型）
